About RailYatra

I wanted to make a simple website where people can look up railway stations in India.

I'm working on it one step at a time and saving my progress through Git commits. Hopefully, it will turn into something useful.

Things I'd like to add

  • Planned a map using Leaflet and OpenStreetMap
  • Planned filters for states and railway zones
  • Planned some charts and railway statistics

These features aren't ready yet. This site doesn't show live train positions.
