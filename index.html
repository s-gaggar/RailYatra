    About RailYatra

    I wanted to make a simple website where people can look up railway stations in India.

    I built it one step at a time, and finally published it on Vercel.

    About the data

    Station details come from the open Indian Railways dataset published by DataMeet (CC0). It is a snapshot from around 2016, so newer stations and recent changes may be missing. Not every station has a state, zone or location recorded, so some counts and the map will only cover part of the data.

    What you can do here

    • Search stations by name or code
    • See stations with a known location on a map
    • Filter the list by state and railway zone
    • Check basic numbers about the dataset

    This site doesn't show live train positions.
